# 整体复核与选中物理对齐（2026-10-16）

范围仍为单人第二关的乡村、小卖部、烧烤。行为来自已提取微信 2.1.12 WASM/元数据与配置；模型、动画、音频主要来自 iOS 1.11.03。没有把这些证据等同于线上热更或全平台完全一致。仅修改本地，未发布。

## 本轮纠正

| 项目 | 有证据的实现 |
|---|---|
| 按下选中 | 变为 kinematic，保留实体碰撞体；Transform 沿相机反方向移动 .4，.2 游戏秒 Linear。删除额外速度清零、连续碰撞/插值切换。 |
| 碰撞与唤醒 | 删除普通第二关选中、取消、收取时的半径扫描和人工 WakeUp。保留真实接触产生的推动；选中对象留在板面管理中，高度优化跳过它。 |
| 取消与成功收取 | 取消才恢复动态并清零线/角速度；成功收取直接提交，不先走取消。收取后仍保留 .05 游戏秒实体碰撞窗口。 |
| 隐藏物品重新显示 | 纠正此前遗漏的 `_changeObjScale` 内部守卫：普通包默认 false，不执行 .75 秒从零长大，也不因此额外禁选。保留受门闩控制的条件分支。创建阶段每 .02 秒增加 .1 的增长是另一条独立逻辑，继续保留。 |
| 显示高度记录 | 手动收取低处物品时，touchHeight = max(物品高度, touchHeight − .5)；自动凑齐跳过。不立即扫描全盘，也不修改历史堆峰。 |
| 打乱 | 用历史记录峰值的下方 7 单位挑选；结束逐候选检查显示/深度 1 的物理，而非额外全盘刷新。常规优化深度仍 .5。默认旋转分支不套用位置打乱分支的显隐与长大。 |
| 暂存 | 按原枚举修正 X/Y/Z 为 OutSine/InBack/OutBack，缩放 InBack。回槽后再维护暂存列，避免杀掉新飞槽动画。 |
| 鹅动作与随机顺序 | `notBeCatch=true` 表示还没被拿走：5–15 秒 InBox；收取后 false：1–5 秒 Outside。按源保留等待前捕获分支，显示/收取重启次序以及先鹅动作、后选择音效的随机调用顺序。 |
| 效果时钟 | 自动凑齐蓝高亮 .3 秒、移出光带与凑齐光束跟随使用真实时间；原粒子系统与背景补间仍使用游戏时间。不能统一改成同一种时钟。 |

可选 ObjectAnim 的 punch 分支在本批 83 个物品及 43 个微信交叉样本中均未绑定，因此没有增加通用缩放脉冲。普通刚体状态切换只改 isKinematic，不额外调用模式设置或 WakeUp。
