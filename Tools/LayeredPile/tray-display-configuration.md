# 槽内展示配置

Unity 菜单：**Goose → 槽内展示配置**。

1. 选择物品（乡村 / 小卖部 / 烧烤摊）。
2. 调整相对相机的 X / Y / Z 角度，查看中央格模型。
3. 调整大小倍率；使用完整七格预览检查是否超出格子。
4. 必要时调整位置偏移：X 向右、Y 向上、Z 靠近镜头。数值 1 表示一个格间距。
5. 点击“保存配置”，重新开始关卡后生效。“重置为默认”移除当前物品的覆盖配置。

乡村 23 种物品已分别设置初始展示姿态。未配置的物品沿用原有行为。切换物品或关闭窗口时会保护未保存的调整。

配置保存在 `Assets/GooseReplica/Resources/Replica/TrayDisplaySettings.asset`。适配模型使用稳定逻辑 ID，重新生成适配预制体后配置仍可解析；原版模型使用预制体引用，同名模型分别存储。配置不修改锅内模型几何或碰撞体。

预览使用实际七格槽资源和游戏相机方向，按游戏目标姿态与格间距显示；预览灯光近似游戏照明，最终效果以真机为准。入槽飞行与槽位重排使用相同目标计算。暂存后重新选择不累乘大小，撤回恢复拾取前的朝向和大小。

## 棋盘大小与批量尺寸分配（2026-10-30）

入口仍为 `Goose / 槽内展示配置`，窗口标题改为「道具展示配置」。上方为棋盘展示，下方为槽内展示。

- 棋盘展示显示自动档位、分配依据、基准最长边、手动倍率和计入全局倍率后的最终尺寸；倍率范围 0.25–2。固定棋盘视野宽度的网格预览使用斜放姿态，不改变实际关卡随机旋转。
- 槽内角度、位置、大小及七格预览保持独立。两组恢复默认只修改各自草稿，点击保存生效；切换/刷新仍保护未保存修改。
- 列表包含关卡预制体及所有已导入模型。导入新模型后点击「刷新列表」即可选择，已选物品按引用保持。
- `Model Adapter` 增加「预览整套尺寸分配」与配置面板入口；一键生成前展示每项建议。名称明确匹配小/中/大三档，基准 1.3/1.9/2.6 世界单位；未知名称默认中档并注明。包围盒体积除最长边立方，大于 .55 缩小 10%，小于 .12 增大 10%，其余不变。规则无随机，不依赖导入顺序。
- catalog 中 `normalizedToSource` 为自动目标最长边/.43，`trayBaseScale` 在迁移前冻结旧尺寸，防止改变棋盘时带动槽内大小。重导已有分类条目保留自动基准及槽内基准。
- 手调棋盘倍率在 `TrayDisplaySettings.boardEntries` 中按 adapter ID 或原版 prefab 引用独立保存。重新导入不写该资产。原版同名模型的棋盘尺寸仍读原版尺寸数据。
- 创建时只在实例根上应用一次棋盘倍率，视觉、Pick、Body 同比例缩放。所有实例均绑定槽内基准，不依赖是否配置 Pose；飞入途中立即移出也使用该基准。
- 现有 catalog 可通过 `Goose / 初始化导入模型大小层次` 幂等迁移，不重写模型、材质或槽内 Pose。只有未分类条目才更新。

自动档位是本项目的初始适配规则，不代表抓大鹅原版逐物品尺寸。碰撞体形状仍沿用现有配置，本次只同步大小。
