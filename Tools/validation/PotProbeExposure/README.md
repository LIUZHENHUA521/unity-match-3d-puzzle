# 探物露出后自动退场

用户确认的行为：关联物品连续约 0.3 秒无遮挡且可直接点击后，探物提示用 0.25 秒缩小淡出；完成后删除该绑定，下一件自然顶上。只清理提示，不取走锅中物品、不扣次数、不改变连消或奖励列次序。

实现使用现有五点网格遮挡检测，并要求至少一个采样点实际命中目标。每帧最多检测一个绑定，每个绑定检测间隔至少 0.1 秒；轮询所有层，实际确认时间会随帧率及绑定数量略有延后。离屏、奖励尚未落地、暂停、弹窗阻挡交互及双指缩放期间不开始退场。暂停冻结退场动画，并重置尚未确认的露出计时；失焦或切后台也会重置确认计时。退场开始后不响应探物点击和长按连线。录像记录退场进度，缺少该字段的旧录像保持原显示行为。

运行：

```sh
python3 Tools/validation/PotProbeExposure/run.py
```

脚本在 `work/pot-probe-exposure/project` 隔离副本中运行 Unity PlayMode 检查。测试使用真实模型射线、UI 与录像恢复路径，覆盖持续遮挡、短暂露出、再次遮挡、暂停确认/动画、退场点击拦截、连线清理、模型缩放与透明度、下层顶上、次数/连消不变、物品保留、回放/旧录像、离屏、奖励飞行、正常逐帧自动清理和切关重置。

报告与退场前/中/后截图：`work/pot-probe-exposure/project/work/pot-probe-exposure/`。报告以 `COMPLETE` 结束才算通过。截图使用几何测试物品，不代表正式美术效果；真机流畅度仍需实际设备确认。
