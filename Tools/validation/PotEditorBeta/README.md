# 编辑器内测关卡验证

服务端 `services/goose-server/test/pot-editor-beta.test.mjs` 验证专用凭据、与真实内测玩家配置的一致性、配置变化、协议/档位校验、缺失配置和禁止写库。

Unity：运行 `python3 Tools/validation/PotEditorBeta/run.py`，自动启动 127.0.0.1:18097 测试接口，第一次返回 tasty-kitchen / 30 个物品 / 90 秒，第二次返回 12 个物品。脚本使用隔离项目，不覆盖当前编辑器或预览凭据。

校验默认使用内测配置、首页两档入口、重复点击只发一次、两阶段数量、服务端限时、重试保留当前关卡，以及内测模式缺失凭据不回落本地关卡。另遍历主题目录中的全部主题及两档入口，校验每层权重数量与模型池一致且为正有限值、切到编辑器配置后无需凭据、使用所选本地主题、清除旧内测快照、两阶段主题和本地限时、重试保留配置，以及切回内测模式。验证后恢复原来的编辑器配置来源和主题偏好。报告：`work/pot-editor-beta/project/work/pot-editor-beta/checks.txt`。

使用：打开「Goose / 测试启动配置」，在「配置来源」选择「内测配置」或「编辑器配置」。编辑器配置可设置主题；两档入口均使用该主题的本地关卡数量和限时，修改在下一次新开局生效。两种模式均提供免费道具，不发放红包。
