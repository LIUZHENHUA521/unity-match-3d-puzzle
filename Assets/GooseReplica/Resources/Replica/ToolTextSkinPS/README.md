# 道具弹窗文字

来自美术提供的道具框-移出/吸铁石/洗牌 PSD，导入透明文字切图及共用空白标题飘带。
共用标题 title 126×62；移出说明 370×91；吸附说明 381×92；洗牌说明 195×46。
在现有 720×1280 UI 设计坐标中按切图像素尺寸显示，保持原比例；不复制 720×1564 PSD 的整屏布局。
面板、按钮、图标使用现有项目资源；按钮继续使用动态“看广告并使用”，不使用原稿“复活”字样。

背景复用 ReviveSkinPS/panel；title-ribbon 覆盖背景内合成的“复活”标题，再显示“道具”。飘带采用原始像素尺寸，与复活背景对齐。

图标背后使用美术的 icon-circle（249×249），保留切图自带透明度，置于图标下方；标题向上偏移 10 像素，对齐飘带主体视觉中心。
