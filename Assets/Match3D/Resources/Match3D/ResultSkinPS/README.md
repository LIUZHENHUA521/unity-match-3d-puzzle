# 通关结算 PSD 资源

来源：Photoshop 中的「胜利结算-排版02.psd」「失败结算-排版.psd」（原稿 720×1565）。仅在临时副本中隔离图层，合并文字与对应按钮/横幅后，裁掉透明边导出 PNG；源 PSD 未修改。

Unity 布局基准为 **720×1280**，没有将原稿纵向拉伸压缩。切片保留原始像素大小及透明度；整页渲染图为 720×1280。遮罩由 Unity 绘制，透出当前游戏画面。

- Prefab：`Match3D/UI/ResultSuccess`、`Match3D/UI/ResultFailure`
- 编辑器重建：Goose Match3D → UI → Build Result Screens
- 验证入口：`Match3DResultValidation.Run`，输出 `work/result-ui/`
- 动画：0.42 秒轻微缩放回弹，0.22 秒遮罩淡入，0.75 秒内进度条与兔子完成移动；使用非缩放时间，入场期间禁用按钮。
- 挑战次数为本机每日累计；第一关自动进入第二关不重复计数，重新挑战计一次。最好成绩按主题与关卡保存在本机。
- 成功返回首页；失败的「重新挑战」和「继续」都重新开始当前关卡。分享在微信运行环境调用分享接口，编辑器显示提示。
- 第一关自动晋级和 PVP 原结算流程保持原行为。
