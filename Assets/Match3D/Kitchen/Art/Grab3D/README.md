# Grab3D Frying Pan

Source: https://grab3d.com/models/food/frying-pan/
License: CC0 1.0 (as stated on source download page).
Original file supplied by user: Downloads/frying-pan.fbx, 2026-11-09.

The FBX embeds the original textures; extracted JPEGs are retained here.
FryingPan.mat uses the base colour and normal maps with restrained Standard
shader reflections. Texture imports are capped at 1024 for the mobile game.

The countryside prefab preserves the previous skillet as an inactive object.
The new visual has no colliders: gameplay retains the existing independent
physics boundaries. Run Goose > Art > Replace countryside frying pan in
Edit Mode to reapply the import and placement.
