# 每日挑战回放验证

- 单人每日挑战两关自动录制；普通模式和 PVP 不录制。实际初盘覆盖 shared-v2 与 daily-v1。
- 首页菜单“每日回放”：我的录像、当天本科/清北高手录像。完整胜局由后台人工设为公开，其余保持私有。
- 管理后台沿用“3D 游戏 / 闯关记录”路由和权限，在页面内新增“每日挑战回放”页签，不新增独立权限或后台。
- 格式 pot-replay-v1，资源版本 pot-replay-resources-1；采样10Hz、检查点5秒、上限2小时/16MiB。本地保留失败队列，64MiB后停止新录像以保护正常游戏。
- 微信使用原生用户文件目录，浏览器作者播放器没有账号或上传服务。存储文件 gzip + AES-GCM，私有数据库保存密钥；玩家只能读取本人或管理员已公开的完整胜局。

## 明确限制

未完成真实微信设备上长局帧耗、断网重启上传和不同机型视觉验收。录像保存物体根节点与渲染显隐，不保存每根骨骼、粒子和声音采样；用于还原操作、槽位和物理物体位置，不保证逐像素一致。中断恢复可能丢失最后一个尚未落盘的5秒窗口。录像数据为客户端上报，不作为发奖或反作弊凭证。上传段暂不自动清理，后续需按运营保存期设置清理任务。
