# Model Adapter：AI 主题模型资源优化

入口：Unity 菜单 `Goose → Model Adapter`。

把 FBX、OBJ 或 Prefab 及其外部贴图放到 `Assets/Match3D/IncomingModels`，刷新列表，扫描后单个或批量生成。

## 设置

- **生成独立的优化贴图和材质**：默认开启。输出放在各道具的 `Generated/ModelAdapter/<ID>/Optimized` 下；源文件、源材质和源贴图导入设置保持不变。关闭则沿用源资源。
- **贴图最大尺寸**：默认 512，也可选 1024；不把小图强制放大。保留外部贴图的法线类型、颜色空间、透明和采样设置。
- **自动压缩贴图**：默认开启，使用 Unity 自动选择的目标平台压缩格式，不硬编码某个移动平台格式。关闭时生成不压缩的副本。副本清除继承的平台覆盖设置，以免原来的 2048 设置绕过尺寸上限；关闭 Read/Write，保留原有 mipmap 设置。
- **三角面提醒阈值**：默认 3000。超过时提醒，生成不会自动减面。

FBX 内嵌贴图通过临时模型副本提取、重新绑定，随后生成独立的优化材质与贴图。临时提取资源在成功后删除。原 FBX 不被修改。无法处理的贴图类型保留并明确提醒；提取或匹配失败会报告错误，不悄悄丢掉贴图。

更新同 ID 时保留现有预制体 GUID。原有棋盘尺寸、槽内配置与碰撞适配流程继续使用。

## 统计口径

扫描只读；生成后的结果和批量明细包含资源统计。

- 三角面按所有 Renderer 网格实例求和，含隐藏子物体和所有 LOD，属于保守总量；唯一网格、材质和贴图分别去重。
- 贴图尺寸是 Unity 当前导入后的尺寸，内嵌贴图尚未被 Unity 解析时会提醒，生成时补充解析后的统计。
- 引用源文件合计按文件路径去重，包含 FBX 中可能内嵌的资源。优化副本保留原始图片文件，源文件合计或项目磁盘占用可能上升。
- 贴图编辑器内存来自 `Profiler.GetRuntimeMemorySizeLong`，用于比较当前编辑器导入结果，**不是最终下载包体，也不是所有设备上的精确显存**。发布平台和最终构建结果决定交付大小。

## 验证（2026-11-06）

Unity 2022.3.62f3c1 批处理运行 `ModelAdapterResourceValidation.Run`，54 项检查通过。覆盖共享资源去重、多个网格实例的面数、512/1024、压缩开关、平台覆盖清理、法线与透明、UV、源文件设置保护、关闭优化、重复更新保留 GUID、非法配置拦截，以及真实 Meshy 内嵌 FBX。

真实牛角包验证：1,026 三角面保持不变；贴图从 2048×2048 变为 512×512；本机编辑器贴图内存从 5,593,104 字节降到 350,224 字节（约 93.7%）。验证仅使用临时资产，未将牛角包接入关卡或保留为正式道具。

复验入口：`ModelAdapterResourceValidation.Run`。可通过环境变量 `MODEL_ADAPTER_TEST_FBX` 指向含内嵌贴图的测试 FBX；未提供时跳过真实模型用例。结果输出到 `Logs/model-adapter-resources-validation.txt`，真实模型报告及预览也在 `Logs/` 下。夹具使用保留名称 `ResourceValidationFixture`，验证结束清理资产并恢复道具目录。
