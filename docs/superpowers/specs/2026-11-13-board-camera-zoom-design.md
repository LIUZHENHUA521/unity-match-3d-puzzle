# 锅内镜头缩放

用户确认：倍率不能小于初始 1.0；双指向内缩回 1.0 时恢复初始镜头布局和位置，物件物理位置及消除进度不变。实现范围为单人游戏镜头，不涉及后台或发布。

- 双指中点为缩放锚点，倍率 1.0～1.6；双指平移查看锅内边缘。
- 以原有自适应镜头为基准，每帧先适配再叠加缩放和平移；限制平移范围。
- 缩回 1.0 后平滑收敛到基准位置，并最终清零偏移；新一局重置。
- 顶部减号、倍率复位、加号：步进 0.2，边界禁用。
- 二指及三指中断后，直到所有触点松开前屏蔽单指取物；来自 UI 的手势不转成锅内缩放；探物槽也取消多指取物。
- HUD 和世界空间收集槽保持屏幕布局；已收集及暂存物件按相机变化重投影，保留屏幕位置和大小，不改变锅内物理对象。
- 飞入、合并、暂存等动画未结束时不接受新的镜头变化，防止已经捕获终点的动画错位；手势仍更新采样基准，恢复时不跳变。

验证：完整项目 Unity 编译、真实相机/碰撞拾取/触点状态机/按钮回调检查，单独渲染 HUD。微信真机多点触摸与手感待体验。
