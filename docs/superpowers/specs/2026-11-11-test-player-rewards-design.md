# 测试账号通关红包与客服兑换

用户已确认：测试账号正常通关发红包，通关红包弹窗按钮为“联系客服兑换”，点击打开现有客服会话。

## 实现

- 所有线上账号经 /rewards/runs 获取正式资格和每日关卡。测试账号不再转入练习或自行换主题；本地编辑器试玩保留不发奖。
- 服务端在新资格中保存 testToolsEnabled（依据账号无限道具权限），开局响应与重试均返回此值。客户端按该快照启用测试道具，保留正式关卡版本与奖励档位，记录真实 test 使用次数。
- 新资格允许测试账号按现有两阶段通关、小时/每日总额、个人每日限额、凭证幂等、库存使用凭据规则结算。无测试权限的资格不能上报测试道具使用。历史资格保留旧测试隔离检查，历史练习局不补发。
- 服务端确认发券后才展示领取弹窗；文案改为“联系客服兑换”，确认回调同步打开现有 Match3DCustomerService.Open。邮件/道具弹窗继续原行为。
- 不改红包金额、支付、身份绑定、清北任务审核或管理后台。本次不执行真实发券/支付；后端部署在实现与验证完成后按部署提醒技能交付确认。
