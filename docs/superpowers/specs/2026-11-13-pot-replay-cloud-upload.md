# 每日第二关回放云存储上传

第一关不再录制和新增上传，已有结算逻辑与历史回放不变。第二关保留实际状态录像，客户端先 gzip 压缩，通过服务端签发、绑定账号及对局的云存储上传凭据直接上传加密文件，再提交完成请求。服务端读取并校验录像，保存加密规范化文件及数据库索引。旧分段接口保留兼容已发布客户端。

采用临时上传会话（30分钟）、随机对象路径、AES-256-CBC 加密传输文件（最终文件仍 AES-GCM），仅服务端绑定的 fileId 可以完成，避免任意文件导入和跨账号提交。文件上传成功但完成失败保留本地队列，重试先完成已有上传，不重复传大文件。压缩文件最大16MiB，展开最大64MiB；对局超过限制时明确显示录制失败原因，不静默丢失。客户端总缓存上限128MiB。后台解压限制同步64MiB。

验证：第二关大于旧16MiB的文件上传与下载、权限隔离、篡改/过期/不匹配拒绝、上传完成幂等与重试、Unity编译与gzip/AES跨语言往返；第一关不开始录制。线上发布保留并行开发中的探物回放改动，不擅自发布未验证的并行改动。
