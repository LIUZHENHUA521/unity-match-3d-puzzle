# 恢复移出暂存槽

用户已确认：移出道具恢复每次移出主槽前 3 个物品到暂存槽；不足 3 个时移出全部。暂存为空时保持现有布局，有暂存物品时特殊连消区域整体上移，取完后平滑回落。主槽和道具按钮固定。

复用 BoardTools 的三列暂存、点选取回和吸附能力；移出时取消目标原有入槽动画，恢复点选碰撞体，保留关卡物品计数。保留现有付费入口和一次扣费语义。复活的整槽回锅与洗牌流程不变。

BoardToolVisual 统一提供暂存展开进度，GameplayBoardLayout 用该进度平移整个特殊连消区域（含提示、星星、计数、四格及点击区域）。按用户截图反馈，暂存底板、列间距和物品缩为原来的 80%，并略微下移保持与主槽的紧凑间距；连消区域上移量由 120 减至 70 个逻辑像素，收紧暂存区上方空隙。验证多宽高比截图。回合重置清空展开进度。

验证：4 个入槽途中移出 3 个、剩余 1 个再次移出、空槽不扣费、暂存点击和取回、展开和回落、重开清理，以及已有连消和复活回归。检查 720×1280、720×1565、768×1024 截图。
