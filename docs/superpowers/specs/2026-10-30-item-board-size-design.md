# 道具棋盘尺寸与展示面板

用户已批准：批量导入自动形成大小层次，并在现有槽内展示面板逐物品调整棋盘大小；棋盘与槽内大小独立，重新导入保留手调结果。

- 导入器按明确的名称类别建议小/中/大档（1.3/1.9/2.6），未知名称中档，结合包围盒丰满程度做有限修正。规则确定性，不使用随机数或批次排序。扫描和批量尺寸列表说明建议和未知分类。
- 归一化 Prefab 最长边仍 .43。catalog 保存自动棋盘尺寸和独立槽内基准。旧 catalog 缺少新字段时保持原行为；迁移现有 23 项只更新 catalog，不重新生成或覆盖已有 Prefab。
- 棋盘手动倍率独立保存在 TrayDisplaySettings 的新列表，通过 adapter ID 或原版 prefab 引用匹配。与槽内 Pose 分开保存/重置，不互相覆盖，重导不触碰设置。
- 现有窗口添加棋盘档位/基准尺寸/倍率/最终尺寸和固定相机尺度的棋盘预览；原槽内角度、位置、大小、七格预览保持。模型列表包括已导入但尚未加入关卡的模型。原有未保存切换与撤销机制覆盖两类设置。
- 运行时在物品根节点应用棋盘倍率，因此视觉和两个碰撞组一起缩放。槽内/暂存目标尺寸不再从调整后的棋盘尺寸推导；保留原来的槽内基准与用户槽内 Pose。撤回恢复真实棋盘缩放，对象池重用不累乘。
- 验证：自动分类/未知回退/确定性，实际生成与重导保存手调，旧设置兼容，视觉与碰撞同比变化，原模型同名隔离，棋盘调整不改变槽内/暂存尺寸，保存重读/重置/撤销，23 项迁移，实际 Unity 编译与现有槽内回归。

不在本次范围：自动生成贴形碰撞体、改镜头、发布构建。自动尺寸是游戏适配建议，不声称复刻原版参数。

## 审查补充与实施顺序

审查已检查自动档位、全局倍率、未配置 Pose 的槽内尺寸、同名原模型隔离、重置草稿、预览坐标。尺寸单位为世界空间，最终尺寸计入现有全局倍率。独立槽内基准在所有创建实例上绑定，不依赖 Pose。棋盘预览保留模型子树变换。两组重置仅修改各自草稿，统一保存。

实施：先扩充 catalog 与独立棋盘倍率存储，再接运行时根缩放和固定槽内基准，再扩充导入/配置窗口与固定视野预览，最后迁移现有 catalog 并做 Unity 编辑器/运行时回归。用户已在当前会话批准整合方案及执行，无需重复确认。
