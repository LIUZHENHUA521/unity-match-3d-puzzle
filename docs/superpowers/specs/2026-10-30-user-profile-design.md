# 用户资料展示（用户已修订确认）

入口为首页菜单个人名片。按720×1280内容区还原PSD，临时副本合并渲染后导出小尺寸PNG，不导出示例文字、相机及编辑图标。

头像、昵称、性别、地区来自微信小游戏授权。首次通过 createUserInfoButton 原生点击授权；已授权通过 getSetting/getUserInfo 自动同步。拒绝、取消、缺字段显示默认头像/微信玩家/未提供，仍可查看账号资料和关闭。用户明确不要相机和手工编辑。

微信资料只用于当前弹窗展示，不上传后端、不持久化，不作为身份或奖励凭证。每次打开重新读取授权状态，关闭销毁原生按钮，迟到回调按generation隔离。原生按钮区域随Unity实际像素矩形换算到微信逻辑像素；窗口变化重新定位。按钮须等待账号就绪；不覆盖关闭区域。头像下载仅允许HTTPS微信qlogo.cn域名，失败回退默认头像，销毁纹理和请求。

账号ID复用 inviteCode（真实稳定游戏ID，非明文openid），展示缩略，复制完整值。注册时间复用服务端createdAt，无客户端伪造。后端仅向所有已有profile响应新增createdAt，不改身份、库存或邮件逻辑。未登录显示连接状态，可重试登录。

验证：桥接模拟已授权/首次授权/拒绝/异常/销毁迟到回调/坐标换算/复制；服务端createdAt稳定且客户端不能改；Unity编译、入口、数据绑定、缺省、关闭、720×1280截图。真实微信账号授权及下载域名配置需真机验证。当前官方网页读取失败，使用仓库随附微信SDK的createUserInfoButton实现作为接入依据，不保证接口在各版本均返回真实性别/地区。
