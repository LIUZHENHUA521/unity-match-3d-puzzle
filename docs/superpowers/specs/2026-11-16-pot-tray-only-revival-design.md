# 仅满槽复活

用户已确认：超时直接失败，仅保留每局一次满槽复活，不增加时间。独立 +180 秒加时道具保留。超时与满槽同时发生时超时优先。

客户端删除超时复活路径，保留 TimeReviveUsed=false 和旧结算字段以兼容接口；满槽复活继续沿用分享/广告、临时收纳、次数与异步回调幂等机制。旧 UI 资源及历史录像协议不迁移。服务端继续接收旧版时间复活结算，不修改历史规则；旧客户端需更新才生效。

验证超时（空槽/满槽）、满槽成功且计时不变、每局一次、失败重试、重复与过期回调、结算 time 字段为零、独立加时仍可用。更新现有编辑器验证，补充可独立运行的真实复活源码测试并检查 Unity 编译。此次不发布小游戏或部署服务。
