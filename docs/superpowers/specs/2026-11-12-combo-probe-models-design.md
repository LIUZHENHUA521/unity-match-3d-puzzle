# 连消探物模型与四摞特殊区

日期：2026-11-12；修订：2026-11-13。状态：用户已批准实现，并明确修订为“恢复锅原比例、取消暂存、移出全槽回锅、复活回锅后洗牌”。素材兼容处理见 `Tools/ComboProbe/README.md`，验证记录见 `docs/combo-probe-validation.md`。

## 目标与已确认交互

在现有 Unity 单人三消中增加连消奖励。特殊区使用疯狂动物消的蓝色四槽素材，放在用户最新截图红圈处（锅的下缘、七格主槽上方）；锅和场内物品在画面中一起上移。不再保留暂存区；特殊区与七格主槽保留清晰间隔。

只用连续消除获得探物模型，不加入极限消除、订单、能量消耗或广告补充入口。四个位置是四摞模型，没有“四个模型总上限”。每次成功发放按 0、1、2、3、0 循环压到对应摞顶；旧模型保留。中途空位不改变发放顺序，不优先补空。

每个模型发放时绑定场上某一个具体物体，不是类型兑换券。只选当前关卡已生成、仍在场上、视口内被其他场上物品遮挡的目标；部分或完全遮挡都可成为候选。不选主槽、正在回锅/被拿取/消除、已回收物体，也不选已被其他探物模型绑定的对象。没有候选时不发放、不推进四槽指针、不积欠奖励；连消仍正常推进。

只允许操作每摞最上方模型：短按请求真实目标进入七格槽；成功接受拿取才移除映射。满槽、暂停、弹窗、回锅、洗牌、转场或无效目标不得消耗奖励。长按显示粒子组成的连接线与目标的穿透遮挡轮廓，松手/取消清理，不执行取物。不提供自动选择或自动消除。

目标被普通点击、吸附等其他路径拿入主槽时，任意层中绑定它的展示模型立即移除，该摞收拢；拿走另一个同款物品不影响绑定。目标自然露出后绑定保持。已取走目标随后撤回/移出回锅，也不恢复已消耗映射。重开、换关、退出清空绑定和四摞，清理粒子、轮廓、输入与延迟回调。

## 连消与三星

首次三消：连消数为 1、三颗星全亮、呼吸光圈激活。连消激活后每次成功人工取物消耗一个机会（普通场上、探物模型取物均计入）；点空、失败点击、长按预览、取消、功能按钮本身不计。

在三次成功取物内再次三消：连消数加 1、三星恢复。第三次恰好三消仍续连；第三次没有三消才归零，熄灭三星与光圈。无时间限制。断连不清空已获探物模型。

星数反馈使用用户提供的 `sunshine.png` 覆盖灰色圆弧，按剩余星位显示黄色进度；扣星退回、消除补满。点亮时短暂闪光并弹跳，熄灭时收缩淡出至灰星。动画只负责视觉展示，快速操作时从当前值衔接，不能排队延迟星数逻辑；暂停冻结，重开/退出清理。

沿用此前讨论的首版默认值：从第 2 连起，普通人工取物促成的每次续连发一个模型。探物模型促成的三消可启动/延续连消、补满星，但不在同次操作发新模型，避免自我供给。回锅后再次点击视为普通人工取物。吸附等自动取物会清理目标绑定，但不扣星、不启动/推进连消、不补星、不发模型；撤回不恢复历史星数。此部分为实现默认值，用户可在审阅时调整。

逻辑依成功接收取物的顺序一次性结算，不按飞行/消除动画结束先后结算。先判断本次逻辑三消，再决定续连或断连，保证最后一星三消、快速连续点击与并行飞行动画正确。对象进入主槽时先清理映射，再选择新奖励目标。

## 位置与不重叠约束

采用统一的屏幕布局计算，基于 720 设计宽度和真实 safe area。由下向上为：工具按钮、七格主槽、四摞特殊区、锅和场内物品。取消暂存区及其占位。镜头的 orthographicSize 严格使用功能接入前的 Match3DThemePresentation.Size(aspect)，只做平面位移，不再为新 UI 拉远镜头。

特殊区的圆形连消指示位于四槽左侧，上方显示“短按取物 · 长按查看”。三颗星围绕圆盘，彩色呼吸光圈位于数字、轨道、星星后方，不能把字或星星照白。四槽模型复用主槽的展示姿态，顶部模型对齐底图槽位中心，下层只向上轻微叠放，不向左右倾斜。按用户最新修订移除数量文字及更新逻辑；数据层保留全部奖励。折叠下层不能扩大触摸区或挤入主槽。

布局验收检查原相机比例保持不变、特殊区与七格主槽的实际 UI 包围盒之间保留间隔。锅模型、物品世界坐标和碰撞体尺寸不因布局改变。紧凑屏也不缩小锅；超短屏可能裁切锅的上缘，不能声称所有比例都能完整容纳锅、顶部 HUD 和新增区域。

2026-11-13 追加布局修订：收紧特殊区与主槽的可见间隙，锅的原大小与上移位置保持不变。连消圆盘、灰色圆弧、Spine 与三星使用疯狂动物消 `main.scene/newCombeNode` 的相对坐标和层级；圆弧图片向上偏移以补偿裁切，圆盘和 Spine 同心。常亮星使用原 `pre_star.prefab` 的 `image_Star.png`，不持续展示 `image_Star_lighe.png` 点亮过渡图。具体对照参数记录在素材 README。

## 移出与复活的修订规则

移出将当前七格槽内的全部未消除物品飞回锅中，不再只移三个，也不再进入暂存；只消耗一次移出使用次数，不自动洗牌。正在入槽的物品也须安全接管，取消旧飞行动画，恢复每件物品入槽前的大小、朝向、碰撞与牌堆物理登记。回锅约 0.48 秒，过程中阻止重复取物和道具操作，暂停会冻结动画。

槽满复活：全部回锅完成后再执行一次既有洗牌，不消耗普通移出/洗牌道具。时间复活保留增加五分钟的原权益，同时执行回锅后洗牌；空槽时也会洗牌。保持现有复活资格、获取途径与次数限制。回锅和洗牌不补星、不发探物模型；已有未消耗的探物绑定保留，已消耗绑定不因回锅恢复。退出或换关取消未完成回锅及后续洗牌，不能串到新局。

具体上移量、四槽宽度和间隔由真实 Unity 横纵比截图校准，不直接照搬聊天截图像素作为世界坐标。必须同时覆盖第一关圆锅与第二关现有容器。

## 实现边界与组件划分

- `ComboProbeState`：不依赖显示组件的三星/连消状态、四摞轮转、目标身份与映射清理。明确取物来源及单次操作 ID，幂等结算。
- `ComboProbeController`：生命周期、候选遮挡检测、原有取物接口接入及奖励派发。候选只在奖励时扫描，不每帧扫描整场；使用单独随机流，不改变每日生成随机序列。
- `ComboProbeView`：原素材 UI、模型展示、堆叠折叠、长短按。展示副本只含可视内容，不能复制可交互刚体、碰撞、音效和业务脚本进入真实牌堆。
- `ComboProbePreview`：长按粒子连线与目标轮廓，统一取消和资源复用；覆盖暂停、切后台、转场等门闩。
- `GameplayBoardLayout`：锅的镜头平移、特殊区与主槽的占位和安全区转换；保持原相机缩放。

`InputController.AddObjectOnStack`/`SourcePick` 是现有单人成功取物与同步三消的接点。扩展时不以 `playSound` 代替取物来源，不用动画回调重复发奖励。真实目标身份采用“当前关卡代次 + 每次生成时分配的唯一对象序号”，对象池复用时重新分配，绑定中同时保留并校验代次、序号与当前实例。现有 `BoardItemIdentity.LogicalId` 是模型类型标识，仅用于展示资源查找，不能用它、名称或可被池复用的实例引用单独表示目标身份。

本期覆盖单人第一、二关以及本地试玩；PVP 不启用探物奖励。现有失败/复活流程继续工作；复活保持当前关已有探物模型，断连状态按实际取物结算，不凭空补星。此功能不改后台、服务器、奖励资格或付费库存；不包含发布线上或提审。

1. 首次三消、第二/多次续连、第三步恰好三消、第三步未消除、断连重新启动；无效点击/长按/工具按钮不扣星。探物三消续连不发奖励；吸附与普通取物来源正确区分，快速输入不重复结算。
2. 至少发放十个奖励，验证 0/1/2/3 循环和每摞 LIFO；中间空槽不改变指针；覆盖下层不删除绑定；无候选不移动指针。同目标不重复绑定。
3. 从场上、吸附和探物入口取走目标，各层绑定正确删除；同关两个同款对象分别绑定，取走其一只清理对应映射；对象池复用后同实例获得新序号，旧绑定不得指向新对象；撤回、移出/复活回锅不恢复已消耗绑定；重开/换关无跨局残留。
4. 长按真实顶部模型出现粒子线与遮挡轮廓；完全遮挡目标也能查看；松手、移动取消、暂停、后台、目标失效立即清理且不误取物。顶部用掉才能访问下层。
5. Unity Play Mode 使用真实玩具模型和素材截图：特殊区为空/四摞多层、移出全槽回锅、复活先回锅后洗牌；两关；9:16、1206:2622、9:20、3:4 和底部安全区。测量可见范围与触摸矩形不重合，检查锅保持原比例、镜头平移以及连线不挡触摸。
