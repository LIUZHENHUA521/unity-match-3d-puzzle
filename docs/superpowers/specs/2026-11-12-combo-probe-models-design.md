# 连消探物模型与四摞特殊区

日期：2026-11-12。状态：玩法及摆放方向已由用户逐项确认，本文待书面审阅；尚未实施。

## 目标与已确认交互

在现有 Unity 单人三消中增加连消奖励。特殊区使用疯狂动物消的蓝色四槽素材，放在用户最新截图红圈处（锅的下缘、七格主槽上方）；锅和场内物品在画面中一起上移。特殊区必须与复活/移出道具的暂存区独立，不得覆盖模型、底板或触摸区域。

只用连续消除获得探物模型，不加入极限消除、订单、能量消耗或广告补充入口。四个位置是四摞模型，没有“四个模型总上限”。每次成功发放按 0、1、2、3、0 循环压到对应摞顶；旧模型保留。中途空位不改变发放顺序，不优先补空。

每个模型发放时绑定场上某一个具体物体，不是类型兑换券。只选当前关卡已生成、仍在场上、视口内被其他场上物品遮挡的目标；部分或完全遮挡都可成为候选。不选主槽、暂存区、正在被拿取/消除、已回收物体，也不选已被其他探物模型绑定的对象。没有候选时不发放、不推进四槽指针、不积欠奖励；连消仍正常推进。

只允许操作每摞最上方模型：短按请求真实目标进入七格槽；成功接受拿取才移除映射。满槽、暂停、弹窗、洗牌、转场或无效目标不得消耗奖励。长按显示粒子组成的连接线与目标的穿透遮挡轮廓，松手/取消清理，不执行取物。不提供自动选择或自动消除。

目标被普通点击、吸附等其他路径拿入主槽时，任意层中绑定它的展示模型立即移除，该摞收拢；拿走另一个同款物品不影响绑定。目标自然露出后绑定保持。已取走目标随后撤回/移入暂存，也不恢复已消耗映射。重开、换关、退出清空绑定和四摞，清理粒子、轮廓、输入与延迟回调。

## 连消与三星

首次三消：连消数为 1、三颗星全亮、呼吸光圈激活。连消激活后每次成功人工取物消耗一个机会（普通场上、暂存区重新取物、探物模型取物均计入）；点空、失败点击、长按预览、取消、功能按钮本身不计。

在三次成功取物内再次三消：连消数加 1、三星恢复。第三次恰好三消仍续连；第三次没有三消才归零，熄灭三星与光圈。无时间限制。断连不清空已获探物模型。

沿用此前讨论的首版默认值：从第 2 连起，普通人工取物促成的每次续连发一个模型。探物模型促成的三消可启动/延续连消、补满星，但不在同次操作发新模型，避免自我供给。暂存取物视为普通人工取物。吸附等自动取物会清理目标绑定，但不扣星、不启动/推进连消、不补星、不发模型；撤回不恢复历史星数。此部分为实现默认值，用户可在审阅时调整。

逻辑依成功接收取物的顺序一次性结算，不按飞行/消除动画结束先后结算。先判断本次逻辑三消，再决定续连或断连，保证最后一星三消、快速连续点击与并行飞行动画正确。对象进入主槽时先清理映射，再选择新奖励目标。

## 位置与不重叠约束

采用统一的屏幕布局计算，基于 720 设计宽度和真实 safe area。由下向上为：工具按钮、七格主槽、三列暂存区、四摞特殊区、锅和场内物品。顶端计时器与暂停按钮保留安全空间。暂存区为空时仍预留完整占位，避免使用移出/复活后锅或特殊区突然跳动。

特殊区的圆形连消指示位于四槽左侧，上方显示“短按取物 · 长按查看”。三颗星围绕圆盘，彩色呼吸光圈位于数字、轨道、星星后方，不能把字或星星照白。四槽模型在各自局部范围内向上/向后错位叠放，只显示有限的顶部层数并标数量；数据层保留全部奖励。折叠下层不能扩大触摸区或挤入锅/暂存区。

布局验收使用实际投影包围盒与 UI 矩形：锅下缘（可交互物品区域）—特殊区（含显示的叠层与标题）—暂存区（含三列模型）—主槽—工具栏，分别保留可见间隔。优先保持物品当前显示比例，通过相机的平面偏移实现整体上移，不只平移锅模型或修改物体世界坐标。物理碰撞、每日固定开局坐标、生成层与物品相对位置不随 UI 调整。紧凑屏不足时统一等比例适配场景可用空间，不能靠遮挡暂存区解决。

主槽、暂存区和特殊区使用屏幕锚点定位，镜头上移后不能跟随场景漂移；暂存底板和暂存模型必须由同一布局结果定位。新区域整个底板消费 UI 指针，点空槽、按住或拖出不能穿透选中锅里物品。长按目标在物理运动中跟随，其销毁、对象池复用、遮挡状态变化不应引起错误目标连线；无效身份立即取消预览。

具体上移量、四槽宽度和间隔由真实 Unity 横纵比截图校准，不直接照搬聊天截图像素作为世界坐标。必须同时覆盖第一关圆锅与第二关现有容器。

## 实现边界与组件划分

- `ComboProbeState`：不依赖显示组件的三星/连消状态、四摞轮转、目标身份与映射清理。明确取物来源及单次操作 ID，幂等结算。
- `ComboProbeController`：生命周期、候选遮挡检测、原有取物接口接入及奖励派发。候选只在奖励时扫描，不每帧扫描整场；使用单独随机流，不改变每日生成随机序列。
- `ComboProbeView`：原素材 UI、模型展示、堆叠折叠与数量、长短按。展示副本只含可视内容，不能复制可交互刚体、碰撞、音效和业务脚本进入真实牌堆。
- `ComboProbePreview`：长按粒子连线与目标轮廓，统一取消和资源复用；覆盖暂停、切后台、转场等门闩。
- `GameplayBoardLayout`：锅的镜头构图、特殊区、暂存区、主槽的统一占位和安全区转换。接入 `Match3DThemePresentation.Fit`、`BoardTools.StorePosition`、`BoardToolVisual.LayoutBackground` 与 HUD。

`InputController.AddObjectOnStack`/`SourcePick` 是现有单人成功取物与同步三消的接点。扩展时不以 `playSound` 代替取物来源，不用动画回调重复发奖励。真实目标身份采用“当前关卡代次 + 每次生成时分配的唯一对象序号”，对象池复用时重新分配，绑定中同时保留并校验代次、序号与当前实例。现有 `BoardItemIdentity.LogicalId` 是模型类型标识，仅用于展示资源查找，不能用它、名称或可被池复用的实例引用单独表示目标身份。

本期覆盖单人第一、二关以及本地试玩；PVP 不启用探物奖励。现有失败/复活流程继续工作；复活保持当前关已有探物模型，断连状态按实际取物结算，不凭空补星。此功能不改后台、服务器、奖励资格或付费库存；不包含发布线上或提审。
