# 每日候选 WebGL 试玩

用户已指定使用 Unity Web 版本嵌入共用管理后台 iframe。沿用已批准的每日同题方案，替换下载/导入文件的主要操作。

- 从同一 Unity 项目构建专用 DAILY_WEB_PREVIEW 标准 WebGL，独立版本目录托管。使用真实模型、碰撞与消除规则；不初始化微信 SDK、账号、奖励、记录服务。仅候选试玩，免费道具。
- 后台候选卡打开竖屏弹窗，首次进入生成两关开局，已有布局直接还原；可切换第一关、第二关、重开。生成过程中禁止操作棋盘。生成后回传固定布局与 JPEG，用户点击保存到草稿，再明确确认试玩；不自动发布。
- iframe postMessage 双向验证精确 origin、source、随机会话；父页保留候选 ID / seed / 日期 / 档位 / 草稿 revision。迟到、跨候选、重复回复不能覆盖新草稿。iframe 不接收管理员 token。导入复用现有后台校验与乐观锁。
- 只允许已保存候选进入。弹窗期间锁定候选选择及表单；关闭销毁实例。加载进度、生成进度、超时/失败重试可见。已锁定日期可只读试玩但不能回存。
- 保留编辑器文件工作台作为离线补充。当前生产客户端兼容确认与发布限制不变。
- 验证标准 WebGL 编译、真实浏览器生成/重开/交互/导出、消息边界、后台构建；提交推送并部署版本化 WebGL 资源和后台，核对线上文件。不会因此启用正式每日同题排期。

审查已通过：试玩为同源可信仓库构建，iframe 不作为同源安全隔离边界。不发送凭据不代表不能访问同源存储；消息校验用于归属，写操作继续由服务端权限与 revision 控制。禁止第三方脚本，CSP 限制资源连接为本站并允许 Unity 必要的 WASM / Worker。
