# Pot 每层指定模型

用户已确认：8 个主题各 26 个模型；每层可指定模型，留空按 types 随机。

## 交互
在现有每日关卡表格增加模型多选（实际缩略图、名称），非空时 types 等于选择数并禁止单独编辑。清空恢复随机；换主题清空各层选择。保留 count/height 设置及每种至少一组三消约束，非法输入显示错误。

## 数据与生成
ChallengeLayer 增加可选 potModelIndices 数组（当前主题 prefabs 的零基索引）；缺失或空数组严格沿用旧随机生成路径。非空必须唯一、整数、位于实际主题模型池内，长度等于 types。固定列表仅约束入选集合；打乱选中列表后按三消组轮流分配、再打乱物品，保证指定模型都出现且无额外模型。
后台与云函数保存、候选身份、导入布局校验均保留新字段。导入必须逐层验证指定集合及完整三消组，不能接受旧预览忽略配置产生的布局。普通/加量/内测版共享母版，减量仍保留每种至少一组。

## 目录与兼容
从 Unity 8 个主题的实际 prefabs 顺序导出后台目录和缩略图，全部 26；保持旧索引顺序、旧协议及持久化业务名称。历史无选择配置无需迁移，已发布开局不改写。

## 验证与交付
覆盖空选随机兼容、指定单种/子集/26 种、重复/越界/数量不一致、切主题、候选快照导入、三版一致。运行后端测试、后台构建、Unity 编辑器验证及 WebGL 预览构建。盘点完整目标工作区变更并提交推送，先部署所需云函数和新预览，再部署后台，核验远端版本。微信上传不在本次范围。

目录导出时逐主题检查 weights/prefabs 的长度、索引和正有限值；保持空权重等权语义，保留已有权重，新增默认 1。运行 python3 Tools/validation/PotEditorBeta/run.py，覆盖全部 8 主题、两档编辑器入口、第一关、第二关初始化及重试。
