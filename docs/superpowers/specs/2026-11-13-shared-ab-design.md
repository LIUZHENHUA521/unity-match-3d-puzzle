# Unity 接入共用 AB 系统

按用户“直接接入”授权，复用现有实验配置、命中、记录、后台和分析同步入口。Unity 登录身份经 goose-server 验证后以短时服务端证明调用现有 hitABTest；配置必须明确选择 Unity AppID，记录和缓存按游戏/账号隔离。客户端异步初始化、最多一小时会话缓存、失败走现状，不自动创建具体实验。

共用后台修正游戏名称并支持 Unity 玩家手工分组和用户记录。已有动物消业务指标不可冒充 Unity 指标，玩法分析关联既有 goose_game_records，不增加重复埋点。完成服务端、云函数、Unity 运行与完整构建验证后，发布相关云函数、goose-server、共用后台和微信开发版本；不提交审核。保留其他任务的工作区改动，隔离构建发布。
