# 启动时收款授权

用户确认复用疯狂动物消商户，并已完成 AppID 关联；要求将收款授权提前到进入游戏时。

- 微信登录及首页就绪后，查询当前玩家在本游戏 AppID、当前出款商户下的授权状态。有效授权不弹窗；查询失败不阻塞游玩，也不误判为未授权。
- 沿用 CommonDialog，标题“开通微信收款授权”，按钮“暂不授权 / 立即授权”。每次启动最多自动提示一次；关闭、跳过、取消均可继续游戏。编辑器和网页预览不自动请求。
- 玩家主动点击后才申请授权并拉起 wx.requestMerchantTransfer。重复点击锁定，支持取消、超时、旧微信版本和网络错误。页面或登录账号变化后，丢弃旧响应。
- 微信回调只表示页面返回，服务端查询 TAKING_EFFECT 才表示授权成功；不把本地缓存或客户端上报作为凭据。
- 服务端身份缺失、来源 AppID 不符时拒绝；不回退到疯狂动物消 openid。授权页等待最多 90 秒，返回后最多查询 5 次、间隔 1 秒，每次网络请求最多 35 秒；所有非生效状态都不能显示成功。游戏弹窗在网络等待时仍允许关闭，下次启动重新查询。
- goose-server 增加认证后的状态/申请接口，身份来自现有 Bearer token 及服务端用户档案；仅调用已部署的 merchantTransferAuth 的查询/申请动作，商户取现有活动商户配置。客户端不能指定收款人、AppID、商户、授权单号或付款参数。返回字段白名单，不暴露 openid、授权号、配置和密钥。
- 本次只提前取得本游戏身份的收款授权，不发券、不付款、不开启红包开关，也不把跨游戏账号绑定视为已经完成。原跨应用兑换链路与本游戏授权的匹配仍须在付款接入时核对。
- 验证：服务端鉴权/越权/参数注入/错误/并发；JS 桥参数、取消、旧版本、异常及重复回调；Unity 编译和实际弹窗交互。真实微信授权需体验版真机验证。
