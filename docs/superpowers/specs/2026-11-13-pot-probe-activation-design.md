# Pot 探物关联激活动效

用户于 2026-11-13 确认动态示意“就是这个效果”，据此实现，无需重复审批。

## 表现

短按探物：卡片位置聚光 0.08 秒 → 小光头带短尾沿现有定位线的弧线传递 0.28 秒 → 锅内绑定物轮廓亮起，模型轻微缩放回弹及一圈光晕 0.20 秒 → 复用已有 0.20 秒出锅和 0.30 秒入槽动画。落槽沿用现有轻弹。总移动约 1.06 秒。透视轮廓及光粒保证埋在物堆里的目标也能被看见；不添加全屏闪光、粗光束或背景变暗。

长按定位保留原行为。新效果仅在取物成功后启动，不依赖仍可交互的预览状态。每次成功取物独立拥有视觉效果，连续点击不抢占前一条连线。光的起点记录点击时卡片位置，终点随实际目标位置投影；模型激活前不位移。

## 数据与生命周期

沿用当前立即接受取物和占槽逻辑，避免延迟窗口里重复选择、槽位超额和错误奖励。只延迟视觉出锅与碰撞接触体的开始时间，三消继续等待所有飞行完成。新的 PotProbeActivation 负责临时粒子和透视绘制，InputController 负责目标位置、缩放和接触体启动，避免两个系统同时写目标变换。普通取物和磁铁不变。

使用游戏时间：暂停同时冻结传光、激活、出锅；恢复后继续。退场、撤回、移回锅、重开、对象池回收会立即清理临时效果。以 token 和 generation 防止对象池旧引用继续播放。失败点击不产生效果、不消耗探物。

## 实现与验证计划

1. 新增 PotProbeActivation；复用现有粒子/轮廓 shader，通过材质参数控制轮廓透明度，默认值保持长按表现。
2. 将探物起点传入已有取物调用；取物飞行增加 0.56 秒前导段，接触体只在出锅时生成。清理路径统一终止效果。
3. 扩展现有 Unity 集成验证：短按接受一次、传光期间原地、激活缩放、暂停冻结、激活后出锅、入槽等待、重复点击及长按兼容、重开清理，并截取真实画面。
4. 在独立验证副本运行 Unity，保留当前工作区其它尚未提交的相机、命名、连消提示改动。

## 审查补充

槽位重排只更改目标槽位置，沿用取物原始游戏时钟，不重播前导动画、不重复创建接触体。激活缩放由位移时间轴统一设置。触发三消时，不使用 Target() 或棋盘/槽列表判断特效存活；使用捕获的对象与 token/generation，清理由取物结束及取消路径负责。验证覆盖传光中重排、探物触发三消等待全部飞行。
