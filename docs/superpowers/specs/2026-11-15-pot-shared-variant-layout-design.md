# 三版共用物品布局

用户要求并确认：所有未增删物品保持原类型、位置、朝向和相对顺序，内测 −n、通关窗口 +n 只改变第二关第一层数量。

采用最大版母版：先用真实 Unity 生成 +n 完整版，再在第一层按类型删完整三消组，得到普通版；继续从普通版删组得到内测版。各类型至少保留一组。优先从第一层 ID 尾部选可删除组，其他层不动。重编号只为兼容已有连续 ID 协议，相对顺序、所有几何与可见/动态状态保持。三版共享第一关快照及第二关阈值。n=0 的版本快照与普通版一致。

新增可选 potLayoutFamilyVersion 标记。只对新保存的草稿启用；历史发布及旧对局继续原快照。共享 JS 派生函数在后台、云函数和服务端逐字节一致；云函数导入以最大版为权威派生并校验普通/内测数据，防止独立随机布局混入；发布再次验证对应关系。

后台按最大版 → 普通版还原截图 → 内测版还原截图顺序生成，三版齐备才原子导入发布。浏览器预览桥接新增可选 exportOpening 请求，仅让已有固定布局还原后导出原始快照和真实截图，不改变微信客户端协议。增加 WebGL 预览版本。

保证仅限初始快照。操作后的物理碰撞和下落仍可因物品增删产生差异，不承诺全程录像相同。

验证：删组容量与类型边界、首层以外逐物品几何相等、重编号相对顺序、任意篡改拒绝、n=0、旧版本兼容、导入发布原子性、真实 WebGL 三版还原及截图、现有 Unity 校验。部署覆盖目标后台及目标游戏服务的全部当前有效工作区内容；先盘点差异和测试，遇无法安全纳入项列明原因，不静默排除其他会话改动。不部署未要求的其他服务或其他云函数。
