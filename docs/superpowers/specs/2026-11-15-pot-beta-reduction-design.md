# 内测每日减量版

用户已确认实施、测试后直接部署，不再请求阶段审批。

内测玩家始终选择当天对应档位普通版第一层减 n 的版本，不受最近通关 72 小时加量影响。使用既有每日关卡菜单、权限和发布流程，新增 potBetaReductionCount 与 potReduced；n 默认 0（未指定初始减量），为非负 3 的倍数，减后首层数量至少等于类型数乘 3。其他层、主题、时间、高度保持相同。普通、加量、减量版本独立候选与种子，共用第一关快照；发布必须整套齐备。配置修改失效所有候选布局，支持三版试玩。

新开局不再读取 beta-current 独立关卡，旧存储保留。历史发布无减量字段时按普通版发给内测；重新发布才启用减量。run 完整快照保持，内测版胜利不更新 72 小时窗口，即便中途取消内测标记。响应仅包含所选版，不泄露其他完整布局。编辑器内测预览读取相同规则，无用户/对局写入。
