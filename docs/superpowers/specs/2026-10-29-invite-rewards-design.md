# 已确认：邀请新人得道具

复用 goose-server，微信 wx.login 的 code 仅由服务器换取 openid。邀请链接携带不含 openid 的邀请编号；新用户首次登录时绑定邀请人，原子增加邀请人数并发放移出、吸附、洗牌各一个。已注册用户、重复登录、自邀和取消分享不发奖励。新用户指本功能上线后首次登记微信身份的用户；旧版匿名游客无法追溯微信身份。

CloudBase 数据库保存用户、邀请编号和消费凭证，事务确保首次注册与奖励一起提交，库存不会随对局或容器重启丢失。登录接口与原有匿名 PVP 会话隔离。密钥只通过服务器环境变量提供，未配置时返回不可用，不模拟成功。

每局仍优先使用各一个免费道具，再使用永久库存。库存消费使用请求幂等编号，服务器确认后才执行效果，期间冻结对局及输入；无效效果退回该凭证。客户端请求失败时保持同一编号重试，不重复扣除。界面显示免费次数加库存。

PSD 复制后导出透明部件，单图不超过 720×1280，裁去透明留白，PNG 无损压缩。Prefab 中背景、标题、图标、说明、邀请按钮、关闭按钮和动态人数分开，沿用 720×1560 UI 编辑基准，较短屏幕整体缩放适配。

验证：重复注册/自邀/已有用户不发奖，并发及重复消费幂等、缺少凭证拒绝；Unity 编译、弹窗渲染、关闭、免费道具与库存消费；真机双微信账号验证待服务部署后执行。当前实现不修改线上服务，收尾询问部署。

恢复细节：待处理消费编号按已认证用户保存。退款（取消）即便先于消费抵达服务器，也会写入已取消终态，迟到的消费不能扣款；退款请求幂等且不凭空增加库存。消费超时尝试取消，最多两次请求后解除对局冻结，未确认取消的编号在下次登录继续恢复，期间禁止新的库存消费。退款后同编号重放不能执行道具。效果同步执行一次，成功后清除持久化待处理编号；崩溃发生于效果和清理之间时按恢复退款（原对局已丢失）。
