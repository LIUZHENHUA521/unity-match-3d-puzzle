# 每日回放：道具与探物

用户已要求完整支持生成探物、使用探物及道具表现。保留实际初盘和物体轨迹，增加每帧的探物状态和表现快照。探物引用使用初盘 tile ID，禁止重放逻辑调用随机奖励、取物或扣库存。记录四列、连消、星数、提示学习状态、奖励飞星、定位预览、激活连线、音效播放进度，以及道具特效和暂存背景。所有动画用回放时间恢复，暂停不推进、拖动不发放奖励，退出清理独立表现。

采用 v2 / resources-2；新播放器兼容 v1，旧录像明确只能展示已记录内容。服务端对新增字段做白名单、数量与 ID 校验，后台识别两版本并增加探物事件标签。客户端日志恢复仍能通过每帧快照恢复，事件同时写入帧以避免中断丢失。

验证：实际场景录制探物生成、使用、多个并发激活与连续吸附；序列化往返；前后跳转、暂停/倍速、退出；服务端拒绝未知目标/越界快照并兼容旧录像。部署服务端、后台和 v2 网页播放器，客户端构建验证。

## 审查补充

- 使用、生成、预览开关、道具效果创建令本渲染帧立即采样，不等下一个100ms；每个表现保存当前 age，播放在采样间隙推进 age。四列以初盘 ID 引用，独立激活按目标 ID，工具效果按实例 key；帧内 events 只用于本地恢复，服务端只保留顶层事件，按 seq 唯一。结束事件先写入最终帧再持久化。
- 覆盖移出（物体与暂存背景）、吸附（物体和粒子）、洗牌（物体和粒子）、加时（倒计时），并显示最近道具使用。回放不恢复可操作库存按钮、不记录无效点击或广告页面；不扣道具、不发奖励。粒子按记录的种子和播放时间模拟，不以逐像素一致作为验收条件。
- 暂停冻结视觉并暂停音频；拖动静默恢复目标时间；继续播放从该音频位置恢复，pitch随倍速。向前跨过已结束的音频不补播。跳转和退出清理不再有效的效果。
- 每帧快照为完整状态，沿用同期已提交的云存储改造：仅每日第二关录制，展开64MiB、压缩16MiB、本地128MiB；72000帧/两小时限制不变，超限停止记录而不阻塞游戏。当前渲染帧到下次5秒落盘间仍可能因进程崩溃丢失；不承诺崩溃瞬间零丢失。
- 先部署兼容两版本的服务端，再部署 v2 播放器和后台，最后客户端。新客户端自身回放可读 v1；高手查询带资源版本，避免旧客户端收到 v2。
