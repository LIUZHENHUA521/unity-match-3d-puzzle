# 放大后新入槽物件过大

2026-11-13。用户报告后停止 0.1.69 的发布父进程、构建脚本和隔离 Unity 进程，停止时尚在构建阶段，没有开始上传。

原因：ItemFlightMotion.PickScale 的原始模型路径依照槽间距调整世界尺寸，备用模型路径却直接使用开局缓存的世界尺寸。镜头放大时，备用路径的新入槽物件随镜头同比变大。

修复：只给备用尺寸路径补偿当前镜头倍率；已有按槽间距适配的原始模型路径保持不变。手动、探物、吸附使用同一入槽目标尺寸，暂存重新布局也复用该尺寸计算。

验证：使用真实 CollectionTray 预制体和生产 ItemFlightMotion，覆盖缓存备用模型、无映射备用模型、原始模型在 1.2、1.6 和恢复 1.0 倍时的入槽/暂存屏幕尺寸。修复前缓存模型在 1.2 倍检查失败，修复后全部通过。连同已有相机和跨局检查，共 57 项 Unity 检查通过。尚需微信真机验证动画观感。
