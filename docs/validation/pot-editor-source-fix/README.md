原因：本机 Unity 偏好仍有旧 `pot.editor.useEditorConfiguration=true`，没有新版 `pot.editor.configurationSource`。此前代码将旧 true 映射到纯本地模式，导致该编辑器跳过后台请求。后台实际配置已经是 revision 5，6 层、495 个物品。

实机：打开正在运行的 Unity「测试启动配置」窗口，截图确认来源为「后台编辑器配置」、主题为「甜蜜小屋」。线上专用只读接口返回 revision 5 / 6 层 / 495 个，与数据库一致。现有对局及重试不热更，回首页新开局读取新版配置。

本轮仅修改 Unity，不修改后台、线上数据或游戏服务。保留其他会话的胜利流程改动。未上传微信版本。
