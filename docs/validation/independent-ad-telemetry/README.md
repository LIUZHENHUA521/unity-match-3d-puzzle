# 独立广告完成事件验证

2026-11-13。实现已完成，共用管理后台已部署；游戏上报服务与小游戏新包尚未发布，线上玩家还未切换新上报链路。

## 改动

- 微信原生完成回调先同步持久化 completed，再通知 Unity；统计不依赖奖励是否应用或关卡是否结算。
- 播放前冻结玩家、播放/关卡/挑战 ID、用途、广告位与版本。缓存无法写入或上下文不合法时不启动广告。
- 按账号隔离的重试队列，支持断网、重开、登录刷新、丢失确认；400/409 隔离保留。收到同事件成功确认才删除。
- UI 取消只脱离奖励回调，已开始播放的原生完成监听保留，互斥直到关闭/错误；未完成广告不计数。
- 服务端事务按玩家+播放ID+completed去重，同一事件内容改变拒绝；不依赖开局/结算是否已经入库。
- 后台新增页面内事件标签，独立完成数和结算奖励生效数分开，支持注册日期 cohort、玩家及用途过滤。键集分页防止迟到提交使 offset 位移；总数是本次查询结果，不宣称跨页事务快照。扫描超过20,000条明确拒绝，不显示部分统计冒充完整总数。
