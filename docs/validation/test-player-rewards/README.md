## 改动

- 测试账号与普通账号都调用 /rewards/runs；服务端保存并返回 testToolsEnabled 布尔权限快照，客户端保留无限道具能力并进入正式每日挑战。
- 正式测试局保留服务端关卡版本和 rewardTier，测试道具次数继续独立记录，不冒充库存消耗。服务端拒绝无测试权限资格上报 test 道具。
- 测试账号正常完成两阶段后按原规则发券；金额、小时/每日总额、个人每日限领、库存凭据校验、重复结算幂等保持原规则。历史资格保留旧测试隔离，历史练习局不补发。
- 通关发券确认后弹窗按钮为“联系客服兑换”，确认回调同步调用现有客服入口。金额来自服务端，详情缺失时显示“红包”，仍可联系客服。邮件/道具领取按钮不变。
