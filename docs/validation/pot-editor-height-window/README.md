# 编辑器六层高度区间修复

用户截图显示新增六层后物品活动范围过宽。排查发现 PotEditorLevelConfig.BuildProfile 覆盖各层高度，却沿用原主题四层的 limitHeight=21.5，LayeredItemPile 用此值初始化可见和动态物理阈值。末层变成 26 时，基准应为 25.5，否则范围下界偏低 4 个高度单位。

修复为配置后的末层高度减 0.5，与每日关卡派生规则一致。显示/物理深度、历史高度下降规则和速度稳定后冻结行为不变。Scene 显示 Collider Gizmo 不等于动态模拟：下层物品关闭渲染且 isKinematic=true，保留实体碰撞体作为上方堆叠的支撑。

新增回归：各主题两档入口下两层高度 14.5/19.5 派生基准 19；另单独构造 6 层 495 个物品，验证 25.5 基准、19.5 初始可见阈值、20.5 初始物理阈值，以及生成后隐藏渲染、下方稳定刚体冻结和上方动态刚体并存。

本轮仅改 Unity 编辑器配置派生逻辑，不修改线上配置、后台或每日关卡实现。保留其他会话未提交修改，未上传微信版本。

验证结果：完整 PotEditorBeta 检查 332 PASS / COMPLETE。用户也已在当前 Unity 中确认生效。
