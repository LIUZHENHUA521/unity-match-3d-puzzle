# 特殊牌顶出时的局部碰撞

用户确认的行为：从连消区域取出底层特殊牌时，轻轻顶动附近未冻结模型；冻结模型保持原样，随后特殊牌正常飞入主槽。

实现：Probe 来源的取物在入槽前增加 0.2 秒、世界竖直方向 0.4 单位的顶出阶段。该阶段使用按模型包围盒估算、半径不超过 0.55 的球形运动学碰撞体与附近物品接触。只允许当前仍在物理管理器内、非运动学、非暂存/入槽的物品参与。物品本身的显示碰撞体保持关闭，避免放大和快速入槽过程中产生失控接触。

碰撞接触对象限制线速度 2.4、角速度 4；未接触物品不施加全局冲量。顶出结束立即关闭临时碰撞，保留原有锅体边界。暂停冻结动画和碰撞阶段，移出、回锅、重开和结束关卡时取消碰撞体。

验证入口：`ComboProbeValidation.Run`。新增真实 Physics.Simulate 接触验证，覆盖附近动态模型上移、冻结和远处模型不动、速度上限、碰撞体回收；真实 UI 点击验证顶出接入、暂停与恢复，保留连消、消除、暂存和复活回归。此为局部碰撞近似，使用简化接触球，避免逐个复杂模型的凹凸形状导致卡住。
