# 两关锅位置统一，以第一关为准

根据用户最新要求，第二关保留第一关锅的完整原始 Transform，不再单独平移锅。
第一关镜头保持原样；第二关仍垂直俯视竖直容器，但镜头位置由第一关锅口中心的
相机坐标推导，取代原来的固定取景偏移 (0,0,-1)。因此两关锅口中心的世界坐标和
屏幕坐标都一致，第一关的位置与玩法不变。

没有修改短段圆滑碰撞轮廓、竖直角度、物品尺寸或相机缩放。
