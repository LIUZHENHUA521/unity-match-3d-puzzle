# 最终修正：第一关原碰撞，第二关新容器与锅对齐

用户要求：保留第一关原碰撞，只在第二关使用“短段圆滑”，并移动锅解决位置偏移。

- 第一关恢复原来的 25 个碰撞盒、出生抽样和锅的位置；不再执行新容器的出生、撤回或颠锅落点校正。
  `FirstStageContainer.json` 与归档的第一关 JSON 逐字节一致。
- 第一关物品清空后，立即停用原碰撞子树，再安装第二关新容器。返回首页、重开第一关都会恢复原配置。
- 第二关把锅沿桌面平移，使锅口中心与新容器上口中心在游戏固定镜头中重合；锅的网格碰撞与模型一起移动。
  没有改变锅的尺寸、角度或镜头。此处对齐的是画面中心，锅的可见口径和隐藏容器口径仍是各自原定尺寸。
- 极端测试发现最大尺寸的薄披萨可被密集物品挤穿 0.3 厚的安全顶盖。已将顶盖向外加厚为 2，
  内侧仍在局部高度 26，容器内部空间和已选轮廓不变。

## 验证结果

Unity 独立快照批处理退出码 0，40,010 次断言通过。

- 三套主题、69 个模型、1,656 组尺寸/旋转/边缘落点通过。
- 6 组 300 物品堆叠测试通过，包含最高层 30、尺寸 1.25 的极端组合，没有物品中心越界。
- 第一关碰撞盒数量、Lv1Col 子树、15 个物品原始出生位置逐一比对通过。
- 两关切换时原碰撞立即停用；新容器只在第二关存在。
- 第一关锅口中心仍为 (0.05, 0.36, -0.04)。第二关锅口和容器口的投影中心误差小于 0.0001 视口单位。
  重复应用对齐不累积偏移。
- 第一关五次三消自然进入第二关，拾取、撤回、颠锅、摇动、重开、返回首页通过。
- 发布暂存保留明确要求的第一关数据，不包含旧第二关及组合容器 JSON。未发布或上传。
