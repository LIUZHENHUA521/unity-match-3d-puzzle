# 启动收款授权验证

日期：2026-11-11。

微信登录完成、首页就绪后查询本游戏当前玩家的收款授权；未生效时显示“暂不授权 / 立即授权”。每次启动最多自动提示一次。已授权、查询失败不弹；授权准备期间仍能关闭；页面/账号变化使旧响应失效。

## 复验

1. 启动 `node Tools/wechat/merchant-authorization-fixture.cjs`（仅监听 127.0.0.1:18766）。
2. Unity 打开本项目场景，创建 `Temp/run-merchant-authorization-check` 文件触发验证。由验证开启的 Play 模式会在结束后退出。
3. 创建 `Temp/compile-merchant-authorization-webgl` 文件执行 WebGL 脚本编译。

初始开发阶段仅完成本地验证；后续上传与部署状态见下方发布记录。模拟结果不代表真实用户已经授权，也不代表奖励已能到账。
