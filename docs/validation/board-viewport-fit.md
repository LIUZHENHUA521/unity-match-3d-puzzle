# 固定关卡视野修复

进入主题时，根据完整场地横向范围及当前模型配置计算视野；模型余量使用包含偏心轴、层级缩放和任意旋转的网格包围球，左右各留 3% 空白。整个主题复用该结果，包括第一关到第二关，不根据物体下落、可见性、拾取或消除调整镜头。屏幕宽高比改变时，仅重新计算正交相机显示范围。相机位置、旋转、物体尺寸、碰撞和生成规则保持原样。

这是对原固定 7.3125 世界单位宽度的有意修订。当前本地模型配置计算出的宽度约 10.52，物体屏幕尺寸约为之前的 69.5%，具体结果随入场时模型配置变化。保守的旋转余量优先保证长条模型完整显示。

验证：

- `BoardViewportFitValidation.Run`：23 个实际 prefab、64 个旋转、左右场地边缘、9:16 / 1206:2622 / 9:20 / 3:4 四种比例，共 94,208 个网格包围盒角点，保留横向 3% 边距。原视野在同一夹具下裁切 13,828 个角点。
- `BoardViewportFitValidation.RunRuntime`：Unity Play Mode 中验证第一关及第二关生成、下落、打乱、拾取和撤回期间镜头稳定；四种宽高比下检查实际可见物体包围盒；比例恢复后镜头范围一致。
- Unity 批处理编译与以上两项验证通过。几何结果见 `board-viewport-fit.txt`，运行结果见 `board-viewport-runtime.txt`。

未发布微信体验版，尚未做手机真机视觉验收。本轮自动验证检查屏幕边缘，不等同于所有设备安全区及 HUD 遮挡的视觉验收。
