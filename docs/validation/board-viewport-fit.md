# 固定关卡视野：90% 试玩版（0.1.28）

按用户真机反馈，将物体屏幕显示大小改成最初镜头的 90%。正交相机尺寸为原适配结果除以 0.9，保留原来的宽高比适配，不再根据最大模型包围球扩大视野。这里的 90% 是相对最初画面，不是相对 0.1.27 的约 70%。

游戏中镜头固定；只有屏幕宽高比改变时重新适配。相机位置、旋转、物体物理尺寸、碰撞和生成规则未改。90% 优先满足大小体验，不再承诺左右固定 3% 空白或极端旋转完全不裁切。

`BoardViewportFitValidation.Run` 在独立发布副本中验证：23 个实际 prefab、64 个旋转、左右场地边缘、9:16 / 1206:2622 / 9:20 / 3:4 四种比例；显示比例均为原来的 90%。94,208 个角点中，原始镜头裁切 13,828 个，90% 镜头裁切 3,072 个。该夹具将所有物体放到场地外缘，是压力测试，不是正常关卡裁切率。

几何结果见 `board-viewport-fit.txt`，运行结果见 `board-viewport-runtime.txt`。真机视觉体验仍需用户确认。
