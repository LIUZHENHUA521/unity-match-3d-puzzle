# 巧克力藏在锅底修复

新平底锅可见内底位于 y≈0.485，旧来源边界在中心的支撑面仍为 y≈0。这会让薄巧克力落在旧碰撞面后被新锅遮住。另一个隐患是 BoardPhysicsSettings 将导入物品的连续碰撞模式覆盖为 Discrete。

修复：Match3DThemePresentation 为替换锅的实际网格安装静态非凸 MeshCollider，使用 WallLayer 和原接触材质，随展示对象一同回收、复用；旧外围边界保留。导入适配物品使用 ContinuousDynamic 防止高速穿过静态锅底，旧来源物品保持原模式。未改变模型大小、点击范围或关卡生成。

验证：独立物理场景对实际巧克力预制体执行 12 组位置/角度/3 与 22 单位高度的落下试验，每组模拟 12 秒，检查可见位置和拾取层射线；全部通过。详见 chocolate-collision.txt。微信端需更新包；已存在的旧局需要重新开始才能加载新碰撞体。

三主题第一关、300 物品第二关、三消与重试回归全部通过。
