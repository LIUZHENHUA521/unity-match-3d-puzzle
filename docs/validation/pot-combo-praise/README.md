## 收益口径

主指标：按新用户聚合、首次命中后 24 小时内挑战开局次数。采用全体分组用户为分母，包含零对局者；只比较已经满 24 小时窗口的 cohort，LEFT JOIN 对局记录，限定本游戏 AppID/实验 ID，排除手工测试账号和首次命中之前开局的对局。

辅助：真实通关率、时长、激励广告次数，报告均值、中位数和分位数；广告次数不能代替收入。留存必须有可靠活跃数据，不能把没有对局等同没有登录。现有共用后台动物消专用分析不直接代表本游戏，需用 `ab_test_records.userId = goose_game_records.userId` 的游戏口径查询。

按随机分组意向（ITT）分析；B 组首局可能因分组尚未返回而未曝光，明确这一稀释。至少覆盖完整一周，样本不足不下收益结论；与正在进行的进度展示实验交叉检查，不能把同期其他改动的效果归给文字动画。

发布状态与实际提交见 `release.json`。开发版本上传不等于体验版或正式上线；未提审，也未宣称已完成微信手机真机验收。
