# 通关奖状与红包验证（2026-11-16）

已实现本科/清北最终通关先展示奖状、玩家确认后展示红包；复用疯狂动物消原图集，Unity 重建卡片入场、横幅回弹、印章落下/回弹、卡片盖章反馈、底部信息和按钮入场。动画约 1.6 秒，使用 unscaledDeltaTime，首次点击可快进。编辑器本科/清北局通关同样展示动画，标注预览且不发红包。

## 数据与兼容

- 正式奖励对局在原 finish 事务内签发证书，写共享 userCertificates。以 pot 命名空间及服务端身份/对局/记录生成稳定唯一键；不填写旧游戏查询的顶层 openid。
- 证书、通关记录及红包事务提交，写失败全部回滚。重复请求返回同一证书；额度不足仍签发有效通关证书。
- 只读核对共享集合权限为 PRIVATE，已有 certificateKey 唯一索引。未更改安全规则、旧数据或云函数。
- 现有账号服务未提供可验证的微信昵称，奖状当前使用「微信玩家」；不会伪造玩家姓名。未增加收藏页或历史证书补发。
- 客户端等待匹配 owner/runId/recordId 回执；早到红包不盖住奖状，晚到回执不覆盖其他局，换号清理展示。领取后仍可从奖状返回首页。

## 复现

运行 `Tools/pot-certificate/export_assets.py` 导出原图集帧；Unity 执行 `PotCertificateBuilder.Build` 生成预制体。执行 `PotCertificateValidation.Run` 运行无需账号/网络的 UI 测试；它会进入临时空场景，关闭 Unity 后输出到 work/pot-certificate-validation。不要在有未保存编辑内容的 Unity 会话中执行。
