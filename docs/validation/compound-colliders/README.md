# 物品贴形组合碰撞验证（2026-11-10）

已将当前 69 个适配模型的整件包围盒改为按网格拟合的实体碰撞。共 242 个形状：222 个盒子、19 个胶囊、1 个球体，每件 1–8 个，平均 3.51 个。简单方形物品保留紧贴外接范围的单盒；篮球用球体；复杂轮廓拆成多个有独立位置/旋转的形状。两款甜甜圈用环形分段保留中心孔洞。

这是基于我们模型的自动近似拟合，不是复制原版物品尺寸，也不等于逐三角面的实体碰撞。新物品缺少实体碰撞时，导入工具使用同一拟合器。已有手工碰撞保持原样；明确执行 `Tools > Match 3D > Rebuild Adapter Body Colliders` 才批量重建当前目录。失败会恢复原 prefab、报告和碰撞目录。

[代表物品三视图](examples.png)、[甜甜圈孔洞](donut.png)、[全部 69 件三视图](all-items.png)：蓝色为模型投影，橙色虚线为原包围盒，绿色为新实体碰撞轮廓。形状体积之和平均为旧盒子的 74.47%，但组合体会相互重叠，这不是实体联合体积或空白减少率；环形物品尤其不能用体积之和衡量孔洞是否保留。

验证使用隔离项目 `work/compound-colliders/project`、Unity 2022.3.62f3c1。最终资源已逐字节同步回主项目。

- 69 个 prefab 与碰撞目录逐项对应，Body 根路径及所有子节点变换保持可恢复；强制应用配置、禁用后恢复、对象池取出/回收再取出通过。
- 所有拟合区域的三角形顶点均在其凸形碰撞体内，裁切前后总面积守恒；另用实际 Unity Collider 检查原网格顶点、边中点、面中心覆盖。甜甜圈中心保持空白。
- 276 组落地：69 件 × 4 种旋转，每组模拟 12 秒，全部落稳且未穿地。
- 使用同一随机种子、300 个模型、同样尺寸/姿态/初始坐标、同一盒形测试容器，模拟 15 秒；修改前后均无逃逸、无非有限数，最终全部休眠。
- 原有网格点击回归通过，包括遮挡、空隙点击后方物品、滑动选择、隐藏与禁用、对象池恢复；69 个适配模型全部通过运行时准备。
- 制造后续模型缺失 Geometry 的失败，确认已经写过的前一个 prefab、报告及目录均恢复到原始字节。
- prefab GUID、模型/材质/刚体/拾取碰撞数据及目录中的尺寸、名称、音效字段保持不变。仅修改实体碰撞组及其配置。原版恢复模型的 SourceColliders 未修改。
