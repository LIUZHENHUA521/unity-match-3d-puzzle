# 全高度关卡结构图

后台每日关卡生成的 `previewImage` 现在使用独立侧视相机，展示全高度物品、当前锅体及实际物理碰撞体线框。普通、加量、内测三版复用各自原有图片保存通道。旧图片不迁移，新生成时生效。

- 540 × 960 JPEG，自适应压缩保证 data URL 不超过现有服务端 180000 字符限制。
- 读取 `LayeredItemPile` 当前持有的 presentation，避免使用已结束的历史 presentation 漏掉锅体。
- 临时恢复高度隐藏的注册渲染器，拍摄后恢复其 enabled/layer；不改开局位置、旋转、缩放、阈值、物理或游戏相机。
- 线框支持 Box/Sphere/Capsule/Mesh，物品仅读取实体碰撞层，排除拾取触发器；保留正常深度遮挡以保证物品可读。
- Unity 实景覆盖 270 / 330 / 390 个物品、连续截图状态恢复、锅体存在、图片尺寸/大小/绿色线框、三轴胶囊/非均匀缩放与高容器取景。
- 后台父子消息边界及配套包共 6 项 Node 测试通过，Vite 构建通过。当前工作区原有通关奖状及红包修改纳入本次浏览器预览构建，PotVictoryFlow 验证通过。

发布版本：`20261117-pot-structure-preview`。目标为既有 CloudBase `/admin` 静态托管及该版本的 WebGL 资源。本次不发布微信包、其他 worktree 或云函数/H5 项目。微信专用混淆开发未用于该浏览器构建（obfuscation=False）。
