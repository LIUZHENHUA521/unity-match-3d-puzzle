# 广告分享频次配置验证（2026-11-16）

## 实现

所有成功应用奖励的广告共用按玩家、服务地址隔离的本地计数；默认广告 3 次后一次道具分享。复活强制广告，待用分享不叠加，成功分享归零。现有库存与持久化标识保持兼容，新计数不迁移旧分享/广告混合计数。

后台入口：`/admin/#/pot-acquisition-config`，菜单「3D 游戏 → 广告分享配置」，页面标题「一锅消不完 · 广告分享配置」。n 限制为 1—100。游戏登录响应下发配置，支持有效缓存、缺失默认 3、读取超时不阻断登录。
