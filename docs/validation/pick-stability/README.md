# 点击物品弹飞修复（0.1.62）

用户反馈 0.1.61 开局乱飞、点击物品会弹开邻居。按用户要求先上传体验用开发版本，暂时保留 `9eb3be71` 的防重叠改动；如果试玩反馈仍不满意，再单独回退该部分，保留连消探物功能。

本次发布仅修改三处运行时代码：

- 单人普通按住仅保留高亮，不再移动有实体碰撞的物品，也不在按住/取消时解除开局冻结。
- 普通取物、特殊探物、磁吸均在动画前关闭刚体检测及所有子碰撞体，取消普通取物的 50 ms 碰撞保留时间。回锅仍使用原碰撞状态快照恢复。
- 开局解除冻结时清除物品残留线速度和角速度，避免在整理后的姿态重放生成阶段的速度。

排查中试过的物理参数、生成活动范围、隐藏生成过程和加速落稳方案没有通过完整回归，均未纳入发布。`BoardOpeningSeparation`、`BoardPhysicsSettings`、`LayeredItemPile`、`Match3DFlow`、`Match3DDailySnapshot` 与 0.1.61 一致。

完整探物回归在重新生成第二关时遇到防重叠搜索预算耗尽（`probe-regression.txt`），未达到 COMPLETE，不能称本轮完整回归通过。该开局整理逻辑按用户最新决定保留，待真机试玩；没有声称开局问题彻底解决。交互定向回归使用已有共享布局，避免随机生成阻止碰撞检查执行。

定向交互检查结果：普通按住/取消不移动碰撞体、开局保持冻结、释放清零残留速度、动态邻居在按住及取物动画中不发生位移或冲量、洗牌与显隐检查通过。见 `interaction-details.txt`。飞行回归执行到末尾的旧版槽间距断言（固定 .994 世界单位）时失败；当前 UI 布局没有在本次修改，未为了通过旧断言改回布局，因此整套飞行回归也未标记通过。
