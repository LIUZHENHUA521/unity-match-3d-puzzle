# 测试启动主题

测试账号点击本科局/清北局，取得每日关卡后弹出主题选择：跟随每日关卡、萌趣玩具、美味厨房、吃货派对。保存最近一次选择作为勾选提示，每次开局仍可自由选择；只修改本次测试关卡副本，不更改服务端每日快照。测试权限沿用既有账号标志，测试局不参与红包结算。取消留在首页。

Unity：Goose → 测试启动配置，选择跟随默认或三套模型。通过 EditorPrefs 在本机记住选择，开始新局生效，两关、预加载和重试保持同一模型池。该偏好不进入发布包。

后台和服务端不新增账号主题配置；普通玩家与好友对战保持原流程。微信测试账号的新入口需要发布新版客户端后使用。

验证：Unity 编译通过；实际运行覆盖三套编辑器偏好、测试主题弹窗的 5 个选项及选择回调、第一关 15 物品、第二关 300 物品、三消及同主题重试。验证结束恢复编辑器偏好及测试权限。
