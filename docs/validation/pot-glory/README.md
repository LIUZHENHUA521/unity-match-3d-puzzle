# 我的荣耀（2026-11-16）

按用户提供的 Photoshop 设计实现首页「我的荣耀」及奖状收藏弹窗。首页入口在原画坐标 (554, 547)，弹窗使用 720×1564 的原稿坐标，按可用区域整体适配；列表独立裁剪滚动，保留顶部标题和底部寄语。

## 素材

原稿为当前 Photoshop 中的 `一锅消-主界面-排版02已命名(1).psd` 和 `一锅消-弹窗-奖状02.psd`。导出只操作临时副本，未保存或更改源 PSD。

9 张 PNG 位于 `Assets/Match3D/Resources/Match3D/PotGlorySkin/`：入口、面板（含标题/奖杯/动物/寄语）、金蓝卡片、奖状/回放按钮、蓝色无字按钮、关闭、新获得。按钮直接用本游戏新 PSD 素材。混合模式光效未烘入透明面板，以避免屏幕混合层导出后出现黄色矩形。

动态文字沿用游戏中文字体：档位 38 px/#833B23，日期 28 px/#8B6049，用时 37 px/#F65300，次数强调 46 px；静态按钮字体保留原 PSD 渲染。数字和日期取真实接口数据，设计稿里的 12/03:28 不进入生产数据。字体开启纵向溢出以兼容中文字体行高，防止短文本框整行不绘制。

## 行为和数据

- 首页新入口与菜单「我的荣耀」打开同一列表。奖状按获得时间倒序排列，每页 10 条；通关总次数由服务端独立统计。
- 查看奖状复用已有动画，历史页按钮为「返回我的荣耀」，不接入发券/领红包回调。
- 每张奖状通过 recordId/runId 关联已上传的通关录像。未同步时保留入口并说明状态；上传完成后刷新列表。重复点击只发起一次下载，失败后可重试。
- 按用户最新要求移除底部「全部录像」「高手回放」两个入口。保留每张奖状的对应回放按钮，退出回放后返回荣耀；历史录像数据和接口保留。
- 新获得标记按账号保存最近已查看奖状 key。切换账号会关闭列表和历史奖状，丢弃迟到请求。
- 新增只读 `POST /pot-replays/honors`，沿用账号 Bearer 鉴权及限流。查询共享 userCertificates 时同时限制 gameId、sourceAppid、sourceUserId，仅返回公开证书字段。通过账号+recordId 的稳定哈希关联录像，并检查 owner/runId/recordId/status/stage。
- 不补发旧奖状、不迁移集合、不写新奖励。未获正式奖状的旧记录不计入荣耀总数；移除底部入口不删除旧录像数据。
