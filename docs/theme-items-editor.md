# 主题物品编辑器

入口：Unity 顶部菜单 **Goose → 主题物品编辑器**。Model Adapter 窗口也有“编辑主题物品（添加 / 替换 / 移除）”按钮。

- 缩略图列表显示当前主题实际使用的关卡物品。
- 导入新素材后先在 Model Adapter 生成适配 Prefab；编辑器底部展开“从已适配模型中选择”，刷新、搜索并添加。
- 替换：将适配后的 Prefab 拖到原物品的对象框，或点击框右侧圆圈选择。保留原物品权重，内部关卡引用自动跟随替换。
- 移除只移出主题，不删除模型文件。
- 不再显示第一关用途选项；内部引用自动维护，删除所引用物品时从剩余物品中补齐。主题至少保留 3 种物品。
- 数量权重默认 1，必须大于 0；它是选中类型后的数量预算比例，不是抽中概率。
- 删除导致池小于层类型数时，保存会下调相应层类型数；增加物品不会自动提高各层类型数。
- 点击“保存主题物品”，下次开局生效。正式配置与源 JSON 同步，重新运行 Import Source Level Plans 不会撤销已保存修改。
- “放弃修改”恢复已保存状态；切换主题和关闭窗口会保护未保存修改。运行或编译中不能编辑。

保存前将关卡资产、源 JSON 及内存快照备份到 `work/theme-items-backups/`。如检测到窗口外修改，保存会拒绝覆盖；先记录需要的改动，再放弃并重新加载。非默认 catalog、各层不同权重的配置暂不支持，窗口会明确提示。

工具不修改旧 ThemeLibrary.prefabs，也不会自动替换现有素材。界面主题名称沿用项目原有标题，目前“乡村每日挑战”对应实际 23 件食物池。

开发验证不再显示在 Goose 菜单中。通过现有编辑器桥发送 `themeitemscheck`，在临时资产副本上验证并自动清理；报告为 `Logs/theme-items-editor-validation.txt`。
