# 连消探物实施与验证

修订日期：2026-11-13。运行环境：Unity 2022.3.62f3c1，Mac 编辑器 Play Mode。设计见 `superpowers/specs/2026-11-12-combo-probe-models-design.md`。

## 已实现行为

- 首次三消进入 1 连消、点亮三星；三次有效手动取物内再消除即续连并补满。最后一星完成三消优先续连；第三次未消除则断连。
- 从 2 连消起，每次普通手动三消发一个探物模型。探物取物参与续连但不再次发模型，自动吸附不改变连消/星数。
- 四列按 1→2→3→4 循环压栈。只显示各列顶部三层及数量，保留全部绑定；短按只取顶部目标，取走下层绑定目标也会同步清理。
- 绑定使用每次生成的唯一序号和关卡代次。复用对象、相同类型、重开和换关均不串绑；无候选不推进轮转。
- 长按 0.25 秒显示真实目标的穿透轮廓与粒子线。松手、拖动、暂停、后台或目标失效取消预览。
- 保留原六张 PNG 与圆形 Spine 动画；连消 1/2/3/4/5+ 使用蓝/紫/橙/红/彩色动画。JSON 的兼容导入说明和重现脚本在 `Tools/ComboProbe/README.md`。
- 对照疯狂动物消真实场景和星星 prefab，统一圆盘/光圈中心，恢复圆弧向上偏移、原版星位及绘制层级。另复用 `image_Star.png` 常亮星星，避免把点亮过渡光晕当作常态。
- 特殊区减少透明占位并下移，收紧与主槽间距，触摸区域不相交；调整间距不改变锅的上移位置或大小。
- 恢复功能接入前的镜头比例；锅只通过相机平移上移，模型尺寸、碰撞体和原始场内坐标不变。
- 取消暂存区和占位。移出将槽内全部物品回锅；复活先回锅，再免费洗牌。时间复活仍增加五分钟。
- 回锅恢复物品原大小、朝向与物理登记，约 0.48 秒；期间阻止取物/重复道具，暂停冻结，换关取消后续操作。已赚取探物奖励保留，已消耗绑定不恢复。

## 验证结果

`ComboProbeValidation.Run`：修订版 150 项断言通过，结果以 `COMPLETE` 结束。使用隔离项目 `Builds/DailyWebProject` 验证，未关闭用户正在打开的 Unity 编辑器。

- 纯状态：最后一星续连、断连、自动/探物来源区分、操作幂等、十次发奖轮转、下层删除与重置。
- 真实关卡：实际射线遮挡、同款不同实例、真实磁吸入口、顶部短按、长按和拖出、暂停、对象池复用、换关/重开/回首页。
- 移出：接管六件正在入槽的物品，一次清空主槽、只消耗一次工具；原大小和旋转、碰撞、牌堆登记恢复，回锅后能再次拾取。无暂存底板，也不会自动洗牌。
- 复活：真实槽满弹窗与免费获取入口，七件物品先回锅、随后洗牌；时间复活保留五分钟，空槽也能完成洗牌。普通移出与洗牌使用次数不被复活消耗。
- 取消：回锅中禁止重复移出、复活、洗牌和拾取；暂停冻结动画；重开取消旧回锅及后续洗牌，不影响新局。
- 显示：缩略图实际包含模型像素，五色 Spine、实际关卡、新复活说明文字均有截图。
- 布局：720×1280、720×1565、720×1600、768×1024 均断言相机比例等于原 Size(aspect)、暂存区不存在、特殊区触摸矩形高于主槽实际图片上缘。场内物品原始世界坐标不随构图改变。3:4 超短屏保持原比例时锅顶会裁切，本轮未声称该比例全锅及顶端 HUD 都能完整避让。
