# 连消探物实施与验证

修订日期：2026-11-13。运行环境：Unity 2022.3.62f3c1，Mac 编辑器 Play Mode。设计见 `superpowers/specs/2026-11-12-combo-probe-models-design.md`。

## 已实现行为

- 首次三消进入 1 连消、点亮三星；三次有效手动取物内再消除即续连并补满。最后一星完成三消优先续连；第三次未消除则断连。
- 从 2 连消起，每次普通手动三消发一个探物模型。探物取物参与续连但不再次发模型，自动吸附不改变连消/星数。
- 四列按 1→2→3→4 循环压栈。只显示各列顶部三层，不显示数量，保留全部绑定；短按只取顶部目标，取走下层绑定目标也会同步清理。
- 探物模型复用主槽旋转配置和视觉轴心还原，按相机空间包围盒居中，不再保留锅里的随机旋转或放大状态；四槽锚点取自底图实际像素中心，下层取消横向错位。数量文字节点、数组和更新逻辑已删除。
- 星数沿灰色轨道显示 `sunshine.png` 黄色弧形进度。消耗从右至左熄灭对应星星并退回进度，消除后补满；点亮采用弹跳和 `image_Star_lighe.png` 短暂闪光，熄灭收缩淡出，底层灰星保留。快速操作从当前视觉值衔接，暂停冻结，重开清理，不延迟修改游戏状态。
- 绑定使用每次生成的唯一序号和关卡代次。复用对象、相同类型、重开和换关均不串绑；无候选不推进轮转。
- 长按 0.25 秒显示真实目标的穿透轮廓与粒子线。松手、拖动、暂停、后台或目标失效取消预览。
- 保留原六张 PNG 与圆形 Spine 动画；连消 1/2/3/4/5+ 使用蓝/紫/橙/红/彩色动画。JSON 的兼容导入说明和重现脚本在 `Tools/ComboProbe/README.md`。
- 对照疯狂动物消真实场景和星星 prefab，统一圆盘/光圈中心，恢复圆弧向上偏移、原版星位及绘制层级。另复用 `image_Star.png` 常亮星星，避免把点亮过渡光晕当作常态。
- 特殊区减少透明占位并下移，收紧与主槽间距，触摸区域不相交；调整间距不改变锅的上移位置或大小。
- 后续按截图微调：蓝色底板、提示、模型和点击区域统一缩小 10%，槽位主体与红色圆盘垂直居中；整组重新水平居中，红圈、星环和锅不缩放。该版隔离 Play Mode 的 150 项验证通过，截图在 `work/combo-probe/compact-panel-results/`，日志在 `work/combo-probe/compact-panel-validation.log`。
- 恢复功能接入前的镜头比例；锅只通过相机平移上移，模型尺寸、碰撞体和原始场内坐标不变。
- 取消暂存区和占位。移出将槽内全部物品回锅；复活先回锅，再免费洗牌。时间复活仍增加五分钟。
- 回锅恢复物品原大小、朝向与物理登记，约 0.48 秒；期间阻止取物/重复道具，暂停冻结，换关取消后续操作。已赚取探物奖励保留，已消耗绑定不恢复。

- 顶部提示按首次消除、剩余取物机会、首次探物使用、常规使用、最后一星切换；首次奖励所在槽轻亮两次。成功使用记录在本次运行内跨关保留，长按/拖动取消不会误完成教学。“连消数”和提示均加粗并相对红圈与顶部页签居中，长提示保持单行。

## 验证结果

`ComboProbeValidation.Run`：最新探物取物与发奖反馈版 281 项断言通过，结果以 `COMPLETE` 结束。使用隔离项目 `Builds/DailyWebProject` 验证，未关闭用户正在打开的 Unity 编辑器。最新结果保存在 `work/combo-probe/reward-feedback-results/`，日志为 `work/combo-probe/reward-feedback-validation.log`。

- 动态提示：真实取物验证 3→2→1 次剩余机会、首次发奖、长按/拖出不误触发、成功取物后立即切换、跨关保留使用记录、断连后已有探物仍提示操作。`hint-earn-probe.png` 验证最长文案，`chance-refilled.png` 展示加粗居中，`chance-one-star.png` 展示最后机会提醒。该轮仅 Play Mode 验证，未重新打 WebGL 包。
- 光圈透明修正：原 PMA 图集被误开启 Straight Alpha Input，造成二次透明度相乘和黑边；修正材质及图集导入设置，保留原 PNG 和 Spine 动画。五色均已实际截图检查，蓝色额外在同一帧用临时旧材质对照（`ring-double-alpha-before.png` 与 `showcase-combo-1.png`），像素差异仅落在光圈区域。该轮未重新构建 WebGL 或发布。
- 最新修正：进度以几何裁切代替模板遮罩，depth=0 与 depth=24 下逐像素比较 0/1/2/3/0 星，零星透明、其余覆盖递增、两种缓冲输出一致。四画幅下特殊区内容矩形均占宽约 97.3%，不横向裁切且主槽分隔检查通过。模型捕获改用场景主灯，`showcase-tray-comparison.png` 对照真实主槽同款模型；缓存随关卡重建。该轮为隔离 Play Mode 验证，未重新构建 WebGL 或发布。
- 纯状态：最后一星续连、断连、自动/探物来源区分、操作幂等、十次发奖轮转、下层删除与重置。
- 探物碰撞：接受取物的同一帧验证刚体冻结、碰撞检测和全部子 Collider 已关闭；在独立 PhysicsScene 中放置真正动态且重叠的邻居，模拟八步后位置和速度不变，未依靠冻结邻居通过测试。
- 发奖动画：即时绑定、落地前拒绝消费，暂停不会提前显示，连发叠放正常收尾；实际磁吸在星星飞行中取走目标后取消反馈，重开取消飞行且不在新局补发。截图 `reward-star-flying.png`、`reward-model-appearing.png` 使用遮挡夹具；`showcase-reward-flying.png`、`showcase-reward-reveal.png` 为实际牌堆。

- 真实关卡：实际射线遮挡、同款不同实例、真实磁吸入口、顶部短按、长按和拖出、暂停、对象池复用、换关/重开/回首页。
- 移出：接管六件正在入槽的物品，一次清空主槽、只消耗一次工具；原大小和旋转、碰撞、牌堆登记恢复，回锅后能再次拾取。无暂存底板，也不会自动洗牌。

- 取消：回锅中禁止重复移出、复活、洗牌和拾取；暂停冻结动画；重开取消旧回锅及后续洗牌，不影响新局。
