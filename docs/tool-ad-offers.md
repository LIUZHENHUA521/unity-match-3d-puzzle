# 道具库存与广告（2026-11-03）

三个单人道具取消每局免费次数。角标只展示服务端库存；本局成功使用过后背景变灰，仍可以再次通过库存或广告使用。

点击先检查玩法条件（例如空槽不能移出/吸附、洗牌进行中），不满足时仅提示。库存已连接且有数量时，通过原 consume/refund 流程扣减并执行；库存为零或账号未连接时展示道具说明弹窗。库存请求进行中或存在未完成扣减时提示稍后重试。

道具说明复用 ReviveClear 的布局、弹出动画、广告重试和关闭交互；替换为现有无文字蓝色面板、道具图标、功能说明及“看广告并使用”按钮。弹窗期间暂停计时，关闭恢复。完整广告成功回调仅授权本次执行；提前关闭/播放失败不执行，不增加永久库存。回调绑定局版本及弹窗版本，切换页面/重开后失效。

RewardedVideoConfig.toolAdUnitId 当前使用与复活相同的已配置广告位，可独立替换。复活的 clearAdUnitId/timeAdUnitId 不变。客户端使用统计 free 为 0，广告使用记录在 rewarded，库存使用单独计算。

验证入口：编辑器非运行模式创建 Temp/run-tool-ad-check，刷新脚本。ToolAdOfferValidation 使用 EditorShowOverride 模拟广告；库存部分需要 Tools/tool_inventory_mock.py 在 127.0.0.1:18764 运行，只操作本地模拟库存。真实微信广告 SDK 播放仍需真机验收。
